# 积分商城礼品卡兑换静态演示

该仓库提供一个完全静态的前端 Demo，用于向客户演示积分商城礼品卡的“查询库存 → 会员兑换 → 凭证追踪”全流程。所有数据存储在浏览器 LocalStorage，无需后端环境即可操作。

## 页面结构

| 页面 | 用途说明 |
| --- | --- |
| `index.html` | 总览流程、功能亮点，提供导航入口。 |
| `catalog.html` | 展示礼品卡库存信息，可按状态筛选。 |
| `redeem.html` | 录入会员信息并发起兑换，生成凭证号。 |
| `history.html` | 查看本地兑换记录，模拟运营追踪。 |

## 快速体验

### 下载到本地

你可以用以下任一方式获取代码：

- **Git 克隆**：如果仓库托管在 GitHub/GitLab 等平台，执行
  ```bash
  git clone <仓库地址>
  ```
  将 `<仓库地址>` 替换为实际的 HTTPS 或 SSH 链接。
- **下载压缩包**：在代码托管平台点击 “Code/Download ZIP” 即可下载压缩包，解压后得到完整目录结构。

### 本地打开页面

1. 在文件管理器中双击任意页面（推荐从 `index.html` 开始）即可直接在浏览器预览。
2. 如需模拟生产环境、避免 LocalStorage 权限限制，可在项目根目录开启静态服务器：
   ```bash
   python -m http.server 8000
   ```
   打开浏览器访问 <http://localhost:8000/index.html> 按照导航操作体验兑换流程。

### 在线快速预览

如果无法本地运行，可将项目上传到任意静态托管平台，例如：

- **GitHub Pages**：将代码推送到 GitHub 仓库，在仓库设置中启用 Pages，选择 `main` 分支的根目录发布。
- **Vercel / Netlify**：在平台创建新站点，关联仓库或手动上传静态文件，部署完成后即可分享演示链接。
- **CodeSandbox 静态模板**：创建一个 “Static” 模板，将 `index.html`、`assets` 等文件拖入左侧目录，平台会自动生成预览链接。

以上方式均不需要改动代码，即可快速在线展示给客户查看。

> 提示：若浏览器阻止 LocalStorage，请改用 `http://localhost` 或部署到静态托管平台后访问。

## 数据说明

- 初始礼品卡信息定义在 `assets/js/data.js` 中，首访页面时会写入 LocalStorage。
- 兑换成功后礼品卡状态会更新为“已兑完”，并将凭证写入 `giftCardHistory`。
- 需要重新开始演示时，可在 `redeem.html` 页面顶部点击“重置演示数据”。

## 自定义方式

- 修改 `assets/js/data.js` 中的卡券名称、面值、使用须知等字段，即可替换成你的真实内容。
- 根据实际品牌风格调整 `assets/css/styles.css`，包括色彩、排版或按钮样式。
- 如果需要演示更多场景，可参考现有结构新增页面或扩展表单字段。

## 兼容性

页面针对桌面与移动端做了基础响应式适配，适合用于销售 Demo、客户培训或内部评审。建议在最新版本的 Chrome、Edge 或 Safari 浏览器中打开以获得最佳体验。
